# הוספת אפליקציה

יוצרים תיקייה נפרדת לכל אפליקציה, עם שם קצר באנגלית ללא רווחים.

```text
apps/example/
  index.html
  play.html
  screenshots/
    home.webp
    practice.webp
```

- `index.html` הוא דף ההסבר. כותבים בו למי האפליקציה מיועדת, מה לומדים בה ואיך משתמשים בה. מוסיפים תמונות מסך אמיתיות עם טקסט חלופי וקישור להפעלה.
- `play.html` הוא קובץ ההפעלה. אם האפליקציה מורכבת מכמה קבצים, שומרים אותם באותה תיקייה ומעדכנים את הקישור בדף ההסבר.
- `screenshots/` מיועדת לצילומים מתוך האפליקציה.

בראש דף ההסבר מוסיפים את השורות הבאות ומעדכנים את הטקסט ואת שם התמונה. דף הבית יוסיף את הכרטיס אוטומטית אחרי הפרסום.

```yaml
---
app_catalog: true
title: "שם האפליקציה"
summary: "משפט קצר על מה שהאפליקציה מלמדת"
thumbnail: "screenshots/home.webp"
thumbnail_alt: "מסך הפתיחה של האפליקציה"
---
```

מיד אחרי השורות האלה בא ה־HTML של דף ההסבר. השתמשו בקישורים יחסיים: `./play.html` ו־`./screenshots/home.webp`.
